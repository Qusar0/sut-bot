# sut-bot

Открытый Telegram-бот для студентов СПбГУТ им. Бонч-Бруевича: расписание, уведомления и данные из личного кабинета.

> Неофициальный проект. Не связан с администрацией университета.

## Что умеет

**Сейчас (этап 1)**
- расписание группы на сегодня, завтра, неделю, следующую неделю, месяц;
- листание по дням и неделям;
- рассылка расписания на завтра (20:00) и на следующую неделю (вс, 18:00);
- уведомления об изменениях в расписании;
- выбор и смена группы (`/change`);
- документы и согласие на обработку ПДн (`/docs`), удаление всех данных (`/delete`).

**В планах** — см. [docs/roadmap.md](docs/roadmap.md): расписание преподавателей и аудиторий, предметы, экспорт в календарь, подключение личного кабинета (оценки, сообщения, файлы группы, отметка на паре), уведомления из ЛК.

## Быстрый старт

Нужен Python 3.12+.

```bash
git clone <url> && cd sut-bot
python -m venv .venv
.venv/Scripts/activate        # Windows
# source .venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
cp .env.example .env          # впишите BOT_TOKEN от @BotFather
python -m bot
```

Тесты: `pytest`.

## Как устроено

```
bot/
  services/sut_public/  парсер и клиент открытого расписания sut.ru
  services/schedule.py  кэш недель, склейка одинаковых запросов, поиск изменений
  services/users.py     пользователи, группы, согласия, удаление данных
  handlers/             обработчики Telegram (aiogram 3)
  render/               оформление сообщений
  scheduler/jobs.py     фоновые задачи (рассылки, проверка изменений)
  legal/                тексты документов и их версии
docs/recon.md           как устроены sut.ru и lk.sut.ru — начните отсюда
```

Источники данных подробно описаны в [docs/recon.md](docs/recon.md).
