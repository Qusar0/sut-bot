# sut-bot

Открытый Telegram-бот для студентов СПбГУТ им. Бонч-Бруевича: расписание, уведомления и данные из личного кабинета.

> Неофициальный проект. Не связан с администрацией университета.

## Что умеет

**Сейчас**
- расписание группы на сегодня, завтра, неделю, следующую неделю, месяц;
- листание по дням и неделям;
- рассылка расписания на завтра (20:00) и на следующую неделю (вс, 18:00);
- уведомления об изменениях в расписании;
- напоминания перед парой (за 5–30 минут), утренняя сводка, тихие часы;
- выбор и смена группы (`/change`);
- документы и согласие на обработку ПДн (`/docs`), удаление всех данных (`/delete`);
- расписание любого преподавателя и аудитории, профили преподавателей с sut.ru, «Мои преподаватели», «Аудитории моей группы»;
- предметы группы: все занятия семестра, прогресс, фильтры по типу занятий;
- экспорт в календарь: файл .ics и подписка для Google, Outlook, Яндекса (нужен `PUBLIC_URL`).

- подключение личного кабинета lk.sut.ru: оценки, сообщения, файлы группы, долги, стипендия, приказы, отметка на паре, уведомления о новом.

**В планах** — см. [docs/roadmap.md](docs/roadmap.md): Mini App; прочее подключение личного кабинета (оценки, сообщения, файлы группы, отметка на паре), уведомления из ЛК.

## Быстрый старт

Нужен Python 3.12+.

```bash
git clone <url> && cd sut-bot
python -m venv .venv
.venv/Scripts/activate        # Windows
# source .venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
cp .env.example .env          # впишите BOT_TOKEN от @BotFather
python -m bot
```

База: локально SQLite, в проде PostgreSQL (`DATABASE_URL=postgresql+asyncpg://...`).
Схема меняется только миграциями Alembic: бот применяет их сам при старте.
Новая миграция после правки моделей: `alembic revision --autogenerate -m "что изменилось"`.

Для разработки: `pip install -r requirements-dev.txt`, затем `pytest` и `ruff check .`.
При каждом push и pull request GitHub Actions запускает линтер и тесты (`.github/workflows/ci.yml`).

## Как устроено

```
bot/
  services/sut_public/  парсер и клиент открытого расписания sut.ru
  services/schedule.py  кэш недель, склейка одинаковых запросов, поиск изменений
  services/users.py     пользователи, группы, согласия, удаление данных
  handlers/             обработчики Telegram (aiogram 3)
  render/               оформление сообщений
  scheduler/jobs.py     фоновые задачи (рассылки, проверка изменений)
  legal/                тексты документов и их версии
docs/recon.md           как устроены sut.ru и lk.sut.ru — начните отсюда
```

Источники данных подробно описаны в [docs/recon.md](docs/recon.md).
