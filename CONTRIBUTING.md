# Как помочь проекту

Спасибо, что хотите что-то добавить!

## Порядок работы
1. Посмотрите [docs/roadmap.md](docs/roadmap.md) и открытые issues — возможно, задача уже обсуждается.
2. Для крупной фичи сначала откройте issue с идеей.
3. Сделайте форк, ветку от `main`, изменения, тесты.
4. Убедитесь, что `pytest` проходит.
5. Откройте pull request с описанием: что и зачем.

## Правила
- **Никаких секретов в репозитории.** Токены, пароли, cookies — только в `.env`. HAR-файлы и выгрузки из личного кабинета не коммитить (они в `.gitignore`).
- **Фикстуры для тестов из личного кабинета — только обезличенные**: замените ФИО, оценки, тексты сообщений на выдуманные.
- **Бережно к серверам вуза.** Любые запросы к sut.ru и lk.sut.ru — через общие клиенты с ограничением частоты. Не добавляйте опрос чаще, чем нужно.
- **Записывающие действия в ЛК** (отметка, ответы на сообщения, заказ справок) — только по явной команде пользователя или включённой им настройке.
- Новые данные о пользователе → добавьте их удаление в `delete_user_data` (`bot/services/users.py`).
- Изменили текст документа в `bot/legal/` → поднимите `version` в `bot/legal/__init__.py`.

## Стиль
- Python 3.12+, aiogram 3, SQLAlchemy 2 (async).
- Тексты бота — на русском, коротко и по делу.
- Парсеры держите отдельно от обработчиков и покрывайте тестами на HTML-образцах из `tests/fixtures/`.
