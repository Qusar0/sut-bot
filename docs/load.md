# Нагрузка

Прогон: `DATABASE_URL=postgresql+asyncpg://... python -m scripts.loadtest --users 10000 --window 60`
(sut.ru подменён заглушкой с задержкой 300 мс, Telegram — пустышкой).

Результат на 10 000 пользователях в 408 группах, PostgreSQL 16 в Docker, обычный ноутбук (2026-10-13):

| Сценарий | Результат |
|---|---|
| Все 10 000 жмут «Сегодня» за минуту (167 запр/с) | p50 4 мс · p95 6 мс · p99 ~320 мс · ошибок 0 |
| Запросов к sut.ru | 408 — по одному на группу, остальное из кэша |
| Расчёт напоминаний для 10 000 | < 1 с |
| Доставка 10 000 сообщений (лимит Telegram ~25/с) | ~7 мин |

**Узкое место — лимит Telegram на рассылку**, а не сервер. Поэтому:
- напоминания при большом числе получателей стартуют заранее (`reminder_lead`), чтобы последний получил их вовремя,
  а в тексте тогда указывается точное время начала пары;
- рассылки идут фоном и не блокируют обработку нажатий;
- одна неделя группы запрашивается с sut.ru один раз, параллельные запросы склеиваются.
