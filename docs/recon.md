# Этап 0. Разведка источников данных

Дата: 2026-10-13

## 1. Открытое расписание (sut.ru) — основной источник

**Страница группы (одна неделя):**
```
https://www.sut.ru/studentu/raspisanie/raspisanie-zanyatiy-studentov-ochnoy-i-vecherney-form-obucheniya?group=<ID>&date=<YYYY-MM-DD>
```
- Без авторизации, обычный HTML (UTF-8), ~137 КБ.
- `date` — любой день недели, отдаётся неделя Пн–Сб, содержащая эту дату.
- Пример: ИСТ-2633 → `group=56882`.

**Список групп** — на той же странице без параметров: 408 ссылок
```html
<a href='?group=56882' class='vt256' data-i='56882' data-nm='ИСТ-2633'>
```
Группы сгруппированы по факультетам (`.vt253` — аббревиатура, `.vt254` — полное название).
Есть также фильтр по образовательной программе: `?obr_progr=2841_286` (`.vt256_op`).

**Разметка недели:**
| Что | Селектор | Пример |
|---|---|---|
| Номер и чётность недели, диапазон | `.vt234` | `Нечётная неделя (7) Пн, 12 октября — сб, 17 октября` |
| Пред./след. неделя | `#rasp-prev`, `#rasp-next` (href с `date=`) | `?group=56882&date=2026-10-19` |

## 4. Личный кабинет lk.sut.ru (снято с живой сессии 2026-10-13)

**Общее**
- Все ответы в **windows-1251** — декодировать явно.
- Сессия на cookie (PHPSESSID). Без браузерного User-Agent статика отдаёт 403 — слать заголовки как у Chrome.
- Признак протухшей сессии: ответ `session_error` → перелогин.

**Вход**
1. `GET https://lk.sut.ru/cabinet/` — получить cookie.
2. `POST https://lk.sut.ru/cabinet/lib/autentificationok.php`, form: `users=<email>`, `parole=<пароль>`.
   - Ответ `0` — неверный логин/пароль.
   - Ответ с `|` (`error=...|users=...|fio=...|ip=...`) — вход заблокирован.
   - Иначе успех → `GET /cabinet/?login=yes` (страница с меню; там ФИО, роль, учебная неделя).

**«Начать занятие» (п. 35–36)** — в `raspisanie.php`:
- До начала: `<span id="knop<rasp>"><a onclick="update_zan(<rasp>)">Кнопка появится в 12:50. Обновить.</a>` — кнопка появляется **за 10 мин до пары**.
- Обновить состояние: `POST raspisanie.php` `open=3&rasp=<rasp>` → JSON `{data: "<html кнопки>"}`.
- Начать: `POST raspisanie.php` `open=1&rasp=<rasp>&week=<week>` → JSON `{data, id}`.

## 5. Нагрузка (цель — 3000 студентов)
- sut.ru: обход 408 групп × 2 недели раз в 3 ч ≈ 0,08 запр/с — безопасно.
- ЛК: 3000 аккаунтов. Опрос «горячих» разделов (сообщения, файлы, дневник) раз в 15 мин = 3000×3/900 ≈ **10 запр/с** — на грани для вуза. Решение: равномерный «размазанный» планировщик, глобальный лимит (напр. 5 запр/с), реже опрашивать редкие разделы (приказы, стипендии, рейтинг — раз в сутки), переиспользовать сессии.
- Автоотметка: всплеск в начале каждой пары (до 3000 запросов за 10 мин) — очередь с лимитом, старт за 0–2 мин после появления кнопки, разброс по времени.
